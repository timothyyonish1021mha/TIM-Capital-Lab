# TIM Capital Lab

**Think • Invest • Measure**

`TIM Capital Lab` is a beginner-friendly investment decision-making website created as a front-end web development project. It uses semantic HTML, responsive CSS, and vanilla JavaScript to demonstrate event handling and DOM manipulation.

## Features
- Investment Decision Engine with user inputs, dynamic investor profile, example allocation, and reset state
- Weekly stock screener using built-in fictional/example data and category filters
- Investor IQ quiz with score and restart state
- Demo newsletter subscription confirmation
- Contact/feedback form that prevents refresh and displays a confirmation
- Responsive mobile navigation
- Educational/not-financial-advice disclosures

## Files
- `index.html` — site structure and content
- `style.css` — responsive layout and visual design
- `script.js` — built-in data, event handlers, and DOM updates

## Important
The project does **not** use live market data. The stock names, metrics, scores, allocations, and results are fictional/example content for educational demonstration only and are not investment recommendations.

## AI Coding Agent
ChatGPT was used to help brainstorm, plan, draft, refine, explain, and test the website. The project remains intentionally beginner-friendly so the code can be reviewed and explained.
